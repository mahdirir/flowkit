Built for the whole lifecycle

Read, shape, discover, verify, export

Discover

Classic alpha, alpha+ for short loops, and a frequency-based heuristic miner. Maximal places grow from causal seeds instead of enumerating 2^n activity subsets.

Ingest

Single-pass CSV with configurable columns, XES 1.0 traces, and OCEL 2.0 object-centric logs. Strict digit checks reject malformed timestamps.

Verify

Footprint comparison, token replay, bounded alignments, precision and generalization. Quality proxies are named as proxies, not sold as exact measures.

Extend

Every reader, writer, algorithm and hook is a registered spec. Built-ins use the same registry as your code, and command hooks run in any language.

Two minutes to a model

CLI or library, same pipeline
Terminal
flowkit -i dataset.csv --summary-only
flowkit -i log.xes -f dot -o net.dot
flowkit -i log.csv --conformance
flowkit -i example.jsonocel --object-type Order
flowkit --list-formats
V library
import flowkit

result := flowkit.discover('log.xes')!
println(flowkit.render_json(result))
println(flowkit.replay(result.log, result.net).fitness)
